SISTEMA WEB DE GESTIÓN TURÍSTICA DE COSTA RICA

Para ejecutar el proyecto:

1. Abrir XAMPP.
2. Iniciar los servicios Apache y MySQL.
3. Abrir el navegador.
4. Ingresar a la siguiente dirección:

http://localhost/proyecto_turismo/public/

Base de datos:
turismo_cr

Para administrar la base de datos:
http://localhost/phpmyadmin/
